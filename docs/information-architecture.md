# معماری اطلاعات

سند کامل: https://claude.ai/artifact/UifCifV2QvCQ6vAY6Px9jj

منبع: نسخه HTML «ALGONET Investment Advisor Demo 13» (فقط برای معماری اطلاعات، فیلدها و فلوها).

## فلو

1. لندینگ: فرم پایه یا دستیار. کاربر واردشده پروفایل‌های ذخیره‌شده و تعداد پروژه‌های جدید را می‌بیند.
2. اطلاعات پایه (۴ فیلد): مسیر همکاری، گروه پروژه، استان، مبلغ. فقط مسیر و مبلغ اجباری‌اند.
3. نتایج: کارت پروژه با درصد تطابق.
4. فیلتر پیشرفته کنار نتایج: مبلغ و بازده، ریسک، پروژه، مکان، شرایط قرارداد. اعمال فوری.
5. پیشنهاد ذخیره شرایط (ورود با موبایل و کد یکبار مصرف).
6. صفحه پروژه: جزئیات، کارشناس و موبایل یا دانلود فایل راهنما.
7. ذخیره پروژه (نیازمند ورود) و مقایسه.

## قواعد

- هیچ فیلدی از نسخه مرجع حذف نمی‌شود؛ فیلدهای اختیاری به فیلتر پیشرفته یا پروفایل می‌روند (`src/data/fields.ts`).
- استان، شهر، گروه، زیردسته و کاربری چندانتخابی‌اند.
- مبلغ و مساحت با اسلایدر بازه‌ای؛ مدت‌ها و درصدها با اسلایدر.
- دستیار حداکثر ۱۰ پیشنهاد با درصد تطابق برمی‌گرداند (`src/lib/match.ts`).
- داده نامعلوم صفر حساب نمی‌شود: نصف امتیاز و برچسب «نیازمند بررسی».
