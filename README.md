# هم‌سرمایه

لندینگ مشاوره سرمایه‌گذاری: کاربر مسیر و مبلغ خود را می‌گوید، پروژه‌های متناسب را با درصد تطابق می‌بیند و با فیلتر پیشرفته کنار نتایج آن‌ها را دقیق‌تر می‌کند.

این مرحله فقط **معماری اطلاعات و ساختار** است. دیزاین (گلس، موشن، هویت بصری) بعد از دریافت مرجع‌های طراحی اضافه می‌شود.

## اجرا

```bash
npm install
npm run dev
```

## ساختار

| مسیر | محتوا |
| --- | --- |
| `src/data/routes.ts` | ۸ مسیر همکاری، زیردسته‌ها و فلوهای مستقل |
| `src/data/taxonomy.ts` | ۱۱ گروه پروژه و زیردسته‌ها با نام کوتاه و نام کامل |
| `src/data/fields.ts` | همه فیلدها: پایه، فیلتر پیشرفته، پروفایل؛ با نوع کامپوننت |
| `src/data/opportunities.ts` | داده نمونه فرضی (پروژه‌ها، صندوق‌ها، موارد فروش) |
| `src/data/site.ts` | نام سایت و نقشه صفحات |
| `src/lib/match.ts` | امتیاز تطابق مشترک نتایج و دستیار |
| `src/types` | مدل داده |
| `src/app` | اسکلت صفحات |
| `docs/information-architecture.md` | خلاصه معماری اطلاعات |

## فنی

Next.js 15 (App Router)، TypeScript، Tailwind 4، راست‌به‌چپ، فونت وزیرمتن، رنگ اصلی `#0F766E`. `components.json` برای shadcn آماده است؛ کامپوننت‌ها در مرحله دیزاین اضافه می‌شوند.

## نسخه اولیه طراحی (۲۰۲۶-۱۱-۱۰)

صفحه‌ها: `/` لندینگ، `/opportunities` پروژه‌ها و فیلتر پیشرفته، `/opportunities/[id]` جزئیات پروژه، `/assistant` دستیار نمایشی، `/saved` ذخیره‌شده‌ها. ورود فقط هنگام ذخیره پروژه یا ذخیره شرایط باز می‌شود (نمایشی؛ هر کد پنج‌رقمی پذیرفته می‌شود).

- آیکون‌ها از پک Iconsax از طریق `src/components/iconsax.tsx` می‌آیند.
- کامپوننت‌های shadcn در `src/components/ui` هستند.
- همه داده‌ها نمونه و برگرفته از نسخه HTML مرجع‌اند (`src/data`).

اجرا: `npm install` و سپس `npm run dev`.
